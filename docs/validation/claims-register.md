# Claims register for review candidate

| Claim | Allowed wording | Evidence | Limitation |
|---|---|---|---|
| Compatibility | Builds and automated runtime contracts pass for Rhino 8/GH1 and Rhino 9/GH1+GH2 | Phase 1 host matrix and full-check log | External interactive acceptance deferred |
| GPU | Portable VAYU GPU execution is available with explicit CPU fallback and telemetry | NVIDIA/Intel device and parity evidence | No universal speedup; AMD pending external hardware |
| Scientific results | Methods, units, assumptions, provenance and deterministic fixtures are documented | Validation documents and tests | Screening is not certification or professional judgment |
| Daylight | Fast point/annual metrics and a pinned Radiance reference path are provided | Daylight validation artifact | Fast Path omits multi-bounce interreflection |
| Optimization | Mixed-variable constrained ask/tell, Pareto, robust and sensitivity workflows are implemented | Study validation and reproducible fixtures | Sensitivity association is not causation |

Forbidden without new evidence: “best”, “fastest”, “unrivalled”, universal accuracy, universal GPU support, EnergyPlus replacement, LM-83 certification, or public-release status before publication.
