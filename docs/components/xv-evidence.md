# XV Evidence, XV Sensitivity+, and XV Fidelity

`XV Evidence` seals a scientific result with scene/result identity, method, Fast/Reference fidelity, execution environment, samples/runtime, assumptions, limitations, citations, and optional parity/reference error. Store the returned JSON beside every figure or Study evaluation; changing any field invalidates its content hash.

`XV Sensitivity+` first generates an immutable Saltelli/Jansen or Morris design. Its `X` output is one branch per external evaluation. Return exactly one `Y` branch for each row; the component then exposes first/total Sobol or Morris μ* values. Never graft, sort, or simplify these trees between generation and analysis.

`XV Fidelity` expects stable candidate IDs, aligned parameter/Fast branches, evidence hashes, and at least two candidates that also have Reference branches. It reports the fitted Fast→Reference correction, propagated uncertainty, and an ordered batch of candidates worth sending to Radiance or another costly reference solver. The score is value per observed reference cost, not a universal proof of optimality.
