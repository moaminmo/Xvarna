# XV Solar Scenarios

Compares two or more `XV Materials` alternatives over one immutable scene, oriented sensor set, and `XV Sun Vectors` schedule. The first scenario is the baseline. Outputs include transmission-weighted received/lost hours, solar-access ratio, full immutable timeline, ranked object loss, exact category partitions, and non-baseline deltas.

Only materials change between rows; compare geometric alternatives with separately built scenes/studies. A material-layer-cap warning indicates that the optical path was intentionally truncated and should be resolved before publishing results.
