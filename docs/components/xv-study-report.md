# XV Report

Runs report analysis through the shared Grasshopper scheduler and writes complete JSON, Apache Parquet, glTF 2.0, a self-contained narrative report, and a standalone interactive viewer. Bootstrap/permutation counts, confidence, alpha, and seed are explicit inputs and are preserved in the result.

The HTML files do not require Rhino, a web server, or a CDN. Share the entire output directory so the separate Parquet, glTF, and JSON research artifacts remain next to the report. Spearman and its interval/p-values are associations, not causal effects.
