# XV Quality

**Purpose.** Selects coherent Basic/Expert sampling, preview and evidence policies.

**Inputs.** preset/mode plus optional sample, convergence and preview controls. **Outputs.** quality profile and assumptions report. Sample counts are integers; convergence tolerances use the metric named by each analysis.

**Method and assumptions.** Basic presets are bounded safe defaults; Expert exposes overrides. A higher preset increases work but is not automatically publication validation.

**Example.** Start with Balanced, inspect convergence, then raise only the analysis that fails its evidence threshold.
