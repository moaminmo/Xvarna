## GitHub release

XVARNA 1.0 is an open-source Rust-powered environmental and spatial intelligence toolkit for Rhino 8/9 and Grasshopper 1/2. It connects solar, sky, daylight, visibility, attribution and multi-objective study workflows through one versioned scene and evidence model. CPU is the canonical reference; portable GPU and Radiance paths expose device, fidelity, fallback and provenance instead of hiding them. See compatibility, measured benchmark tables and limitations before use.

## LinkedIn / McNeel forum

I built XVARNA to make computational-design analysis faster to iterate and easier to explain. A geometry edit can reuse an incremental scene; a result can identify the occluder that caused it; a design study can leave behind a portable evidence trail rather than only a screenshot. The 49 Grasshopper capabilities cover solar/daylight, spatial visibility and Study/optimization/report workflows on Rhino 8 and Rhino 9. Source, methods, examples and measured evidence are public with the release.
