## Executed validation

- Rust workspace: **173 tests passed**, no ignored tests; strict Clippy and release build passed.
- Managed tests: **87 passed on net8.0 and the same 87 on net10.0**. These are not 174 independent test cases.
- GH1 and GH2 Release builds passed without warnings.
- Installed Rhino 8 runtime: construction of all 49 GH1 components passed.
- Installed Rhino 9 WIP GH2 runtime: all 49 components and SVG icons constructed, component identifier parity checked.
- GH2 runtime gate exercised native scene/ray, CPU VAYU, delta TLAS, sensor grid, sky-view factor, daylight, target view, Pareto and evidence/example contracts.
- SVG syntax, PNG dimensions and both component manifests passed; icon sheet inspected at 24 pixels and enlarged scale.

Runtime construction/contract tests are not interactive acceptance tests of every canvas workflow. CPU/GPU comparisons in the repository are bounded evidence, not universal device equivalence.

## Claims and boundaries

| Capability | Supported interpretation | Boundary |
|---|---|---|
| Solar position | Implemented algorithm and numerical fixtures | One reference case does not establish accuracy over the entire supported domain |
| Fast daylight | Direct/diffuse proxy with documented assumptions | Omits full interreflection; do not report it as a Radiance-equivalent simulation |
| Radiance workflow | Export/runner integration exists | External Radiance runs were not repeated in this review |
| Compute backends | Canonical CPU f64 and portable GPU f32 with budgets/fallback | Accuracy/performance depend on device, geometry and workload |
| Optimization | Implemented MC-EHVI and documented study paths | Not qNEHVI or MF-HVKG; no new comparative optimality claim |
| GH1/GH2 parity | 49 capability contracts and matching identities | Does not prove identical UI behaviour under every host release |
| Interactive operation | Async/scheduled operations and cancellation paths | No general real-time latency guarantee |

The Rust/core and .NET product version numbers describe different release surfaces; they are not interchangeable compatibility promises. Independent datasets, cross-platform/device validation and interactive host acceptance remain release evidence to collect.

## Reproduce

```powershell
cargo test --workspace --all-targets --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo build --release --locked
python tools/check_icons.py
dotnet test dotnet/Xvarna.Tests -c Release
pwsh -File eng/test-rhino8-compat.ps1 -Configuration Release
pwsh -File eng/test-grasshopper2-compat.ps1 -Configuration Release
```

Build/stage the native library and plugins using the repository build instructions before runtime gates. Installed Rhino SDKs are required; proprietary binaries are excluded from source distribution.
