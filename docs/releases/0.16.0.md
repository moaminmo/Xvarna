# XVARNA 0.16.0 — VAHMAN Study/Optimization/Report platform

Version 0.16 turns VAHMAN from an in-memory analysis/optimizer API into a persistent design-study platform.

## Delivered

- Draft 2020-12 Study Manifest schema with named parameter, scalar/vector objective, constraint, baseline, optimizer, and metadata registries.
- Hash-protected variant/evaluation ledger and exact optimizer checkpoints containing the PRNG, archive/population, IDs, and pending candidates.
- Journaled batch begin/resume and atomic, complete, exactly-once/idempotent commit.
- Constraint-aware Pareto fronts and vector objective flattening shared by ranking, tables, and visualization.
- Spearman association with bootstrap confidence interval, two-sided permutation p-value, and Holm family-wise correction.
- Baseline parameter/objective comparison and aligned indexed/spatial delta maps.
- Complete JSON, typed Snappy Parquet, embedded-buffer glTF 2.0, self-contained report HTML, and standalone interactive viewer.
- Additive C ABI, .NET 8/10 API, six CLI workflows, and `XV Manifest`, `XV Workspace`, `XV Commit`, and `XV Report` for Rhino 8/9 Grasshopper.
- ABI/package/schema version `0.16.0` and a 42-component Rhino compatibility gate.

## Validation

The release gate proves schema validity, deterministic checkpoint restoration, crash recovery, exact batch resume, idempotent commit, Parquet readback, glTF structure, embedded offline viewer data, native ABI layout, managed cross-ABI execution, and CLI end-to-end operation. See `docs/validation/study-platform.md`.

## Limits

Sensitivity describes rank association and is not causal. The workspace assumes one authoritative writer. The viewer is local/offline rather than a hosted collaboration service. Independent user testing, multi-project benchmark comparisons, and reviewer validation remain release-1.0 gates; this engineering milestone is not itself evidence of universal optimizer or product superiority.
