# XVARNA 0.4.0 — ZURVAN + HVARE Time and Solar Attribution

Released 2026-08-31 as an engineering milestone for Windows x64, Rhino 8.20+/.NET 8, Rhino 9/.NET 10, the public managed/C APIs, and the standalone CLI.

## Product surface

- `XV Period`: fixed-offset, interval-centred, weighted schedule construction.
- `XV Sun Vectors`: apparent altitude, azimuth, vectors, active filter, atmosphere/north metadata, and deterministic Sun Set.
- `XV Sun Hours`: Direct Sun Hours, Shadow Hours, Eligible Hours, Solar Access, counts, dominant blocker, complete temporal state, and first-hit attribution.
- `SolarEngine.Calculate` and `XvarnaScene.AnalyzeDirectSun`: public managed APIs on .NET 8 and .NET 10.
- `xv_sun_positions` and `xv_scene_direct_sun`: additive fixed-layout C ABI functions.
- `xvarna sun-position`: independent human/JSON scientific diagnostic.

## Native implementation

- Rust 1.96 and `f64` through schedule, sun position, scene, ray, aggregation, and ABI.
- Reda–Andreas SPA with explicit Delta T, pressure, temperature, elevation, true north, and altitude threshold.
- Batched closest-hit execution over the 0.3 ZAMYAD BLAS/TLAS scene engine.
- Sensor-major classification with stable object/instance/mesh/triangle/distance attribution.
- Weighted metric aggregation and deterministic dominant-occluder tie-breaking.
- BLAKE3 identities for Sun Set and direct-sun result.

## Verification shipped with the source

- Published NREL SPA golden case in native Rust, C ABI, and managed .NET tests.
- Analytic blocked/visible/back-facing/category-mask cases.
- Millimetre-model end-to-end managed test preserving source units and attribution.
- Fixed ABI layout assertions for every new options/input/output structure.
- Identical Rhino 8 `net8.0` and Rhino 9 `net10.0` component builds with warnings treated as errors.

This release validates solar position against a published reference case. It does not claim NREL certification, irradiance/daylight equivalence, or replacement of Radiance/EnergyPlus workflows.
