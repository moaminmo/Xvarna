# XVARNA 0.7.0 — MEHR Surface Intelligence

Released 2026-08-31 as a complete engineering milestone toward the 1.0 flagship.

## Product release

- Deterministic native longest-edge sensor grids from Mesh/Brep/Surface/Extrusion geometry.
- Exact area weights, stable IDs, source-face/depth provenance, area-conservation report, hard cell ceiling, and BLAKE3 identity.
- `XV Sensor Grid` with direct points/normals/areas/IDs and analysis-mesh outputs.
- Sensor-ID-safe annual result mapping and bakeable full-domain Viridis solar maps.
- Native area-weighted mean/P10/P50/P90 and exact-edge-connected eligible opportunity regions.
- Transparent PV screening proxy with incident energy, area, module efficiency, coverage, multiplicative losses, kWp, kWh, and kWh/kWp.
- `XV Solar Potential` for Rhino 8 and Rhino 9 with per-cell outputs, region meshes, immutable result, assumptions report, and explicit non-bankable limitation.
- Two-pass public C ABI, .NET 8/.NET 10 API, and `surface-grid` CLI with CSV/OBJ export.

## Validation

The release includes area conservation, resolution, determinism, resource-bound, unit-scale, weighted quantile, connected-region, PV arithmetic, C layout/two-pass, dual-managed-runtime, Rhino 8 runtime-load, and Rhino 9 SDK compile gates. The method, equations, limitations, and current conservative region-fragmentation case are public in `docs/validation/surface-intelligence-and-pv-proxy.md`.
