# XVARNA 0.19.0 — Grasshopper 2 capability connector

Date: 2026-09-04. Channel: local release candidate.

## Delivered

- Independent `.NET 10` `Xvarna.Grasshopper2.rhp` built against the exact official
  `Grasshopper2 9.0.26237.15343-beta` contract.
- 49 operational capability adapters spanning setup/diagnostics, scene and VAYU compute,
  solar/sky/irradiance/surface workflows, DAENA view and attribution, daylight/Radiance,
  Study/optimization/reporting and Evidence/multi-fidelity.
- Exact semantic identity parity: each GH2 `IoId` equals its GH1 capability GUID.
- Native GH2 mesh/point/vector/transform/twig interfaces for geometry-first operations and
  typed, versionable JSON requests for high-dimensional scientific records.
- Shared host-neutral `XvarnaSolarPeriod` moved into `Xvarna.Native`, eliminating duplicated
  GH1/GH2 time semantics.
- Installed-runtime compatibility automation with an expanded numerical contract probe across
  rays, surface subdivision, Sky View, daylight, Target View, Pareto ranking and evidence.
- GH2 included in the solution, full check, Rhino 9 ZIP/Yak packaging, release provenance and
  tracked request examples.

## Compatibility

| Host | Connector | Runtime |
|---|---|---|
| Rhino 8.20+ / Grasshopper 1 | 49-component `.gha` | .NET 8 |
| Rhino 9 / Grasshopper 1 | 49-component `.gha` | .NET 10 |
| Rhino 9 / Grasshopper 2 | 49-component `.rhp` | .NET 10 |

Rhino 8 + Grasshopper 2 is not claimed. The current GH2 SDK has a RhinoCommon 9 dependency.

## Evidence boundary

The installed-runtime and native numerical gate passes locally, but GH2 itself is prerelease.
Interactive canvas placement, save/reopen, preview, progress/cancellation and packaged Yak
acceptance remain required before public upload. Complex GH2 components currently prioritize
lossless versioned JSON requests over custom prerelease goo types; this is a deliberate UX
trade-off and not a claim of identical GH1/GH2 canvas signatures.
