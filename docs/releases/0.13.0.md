# XVARNA 0.13.0 — ZAMYAD/VAYU Lifecycle

XVARNA 0.13 closes the scene-lifecycle and bounded-compute infrastructure milestone.

## Highlights

- Immutable scene deltas with static/dynamic layers and per-layer TLAS reuse, refit, or rebuild decisions.
- Shared BLAS resources and replacement of one mesh without rebuilding unrelated resources.
- True two-level VAYU TLAS/BLAS instancing in WGSL with exact source attribution.
- Deterministic out-of-core geometry chunking under explicit resident geometry and total GPU-memory budgets.
- Versioned BLAKE3 memory/disk portable-plan cache with atomic writes, bounded eviction, corruption recovery, and public telemetry.
- Revision-aware Grasshopper scene/backend reuse plus `XV Cache` and `XV Scheduler` components.
- One bounded scheduler for compute-heavy analysis components with cancellation, progress phases, queue telemetry, and stale-result suppression.
- Additive ABI 0.13 contracts in Rust, C, .NET 8, .NET 10, Rhino 8, Rhino 9, and CLI.
