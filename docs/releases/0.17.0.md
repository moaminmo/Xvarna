# XVARNA 0.17.0 — Feature-complete core development line

Status: **local release candidate; not yet published to a remote package server**.

The development line now closes the core/time/interoperability, product-experience, freeform-envelope, and automated release-quality contracts:

- first immutable local engineering baseline for 0.16;
- complete canonical scene JSON and checksummed `.xvscene` serialization;
- deterministic schema migration and tracked JSON Schema;
- optional tolerance welding and consistent/outward normal repair;
- exact triangle/AABB ROI clipping;
- ASCII/binary STL, ASCII/binary PLY, embedded glTF 2.0, and GLB 2.0;
- glTF primitives, accessors, buffer views, active scenes, node hierarchy, instancing, and transforms;
- WEA and lossless XVARNA weather CSV;
- missing/leap/gap policy, linear interpolation, weather filters, and weekly occupancy masks;
- CLI conversion, scene pack/unpack, and weather normalization workflows.
- document-scoped `XV Quality`, `XV Units`, and `XV Diagnostics` policy and preflight components;
- Preview/Balanced/High/Publication presets, Basic/Expert experience, Live/Manual execution, shared debounce, explicit stale-result retention, and cancellation/progress telemetry;
- unified robust Full/Percentile/Symmetric/Fixed legends with Viridis, Cividis, and diverging palettes;
- sample scaling and evidence/convergence labels across flagship daylight, solar, and visibility analyses;
- freeform material-aware Solar/Shading Envelope with a normalized axis per candidate, closest ray/axis constraints, axis-distance outputs, controlling sensor/time provenance, and backward-compatible World-Z behavior;
- additive native ABI and .NET API for oriented candidates, CLI 4/7-field candidates, and Rhino endpoint previews;
- spatially indexed sparse Visibility Graph with finite-radius 27-cell search, deterministic nearest-candidate ordering, a hard endpoint degree cap, additive Rust/C/.NET/CLI/Grasshopper contracts, and a 100,000-node safety limit without all-pairs output;
- deterministic scene and scientific-result soak runs, checksum mutation/truncation rejection, and a managed line-coverage gate of at least 85%.

The slices are enforced by the strict workspace lint/test gate, deterministic command-line round trips, GPU/CPU parity, native ABI checks, managed tests for both target frameworks, installed Radiance execution when present, malformed-binary corpus tests, and isolated runtime loading of all 46 Grasshopper components in Rhino 8 and Rhino 9/WIP.

The local distribution gate produces host-specific Rhino 8/9 Yak packages, ZIP archives, CLI and SDK archives, SHA-256 checksums, a machine-readable release manifest, and four Grasshopper onboarding documents generated inside Rhino. Public microbenchmarks record parity and complete timing on NVIDIA RTX 5060 Laptop and Intel integrated GPUs; the tiny analytic corpus is explicitly not a speedup or competitor claim. This file does not claim that 0.17 has been uploaded to a remote package server. Public-release evidence still requires AMD execution, representative architectural scenes, and external architectural beta projects. Those are empirical launch gates rather than missing engine APIs.
