# XVARNA 1.0.0

**Status:** publication draft. Do not publish or tag until the signed go/no-go record passes.

XVARNA 1.0 unifies 49 Rhino/Grasshopper capabilities over one Rust scientific core: incremental scene/GPU execution, solar/sky/irradiance/daylight, spatial/view/privacy attribution and Study/optimization/evidence/report workflows. The intended release supports Rhino 8.20+ with GH1 and Rhino 9 with GH1/GH2 on Windows x64, using .NET 8/10 connectors respectively.

Release assets will include Rhino 8/9 Yak and ZIP packages, CLI, SDK, checksums, release manifest, CycloneDX SBOM, benchmark/validation evidence and citation metadata. Measured compatibility and limitations—not comparative marketing claims—govern launch wording. See `docs/validation/claims-register.md`.

Pending before this draft becomes final: external interactive acceptance, AMD and soak evidence, beta KPIs, independent sign-off, license/name decisions, artifact signatures, DOI/site and public upload verification.
