# XVARNA 0.15.0 — Daylight and Radiance

This engineering milestone closes the planned daylight platform slice.

## Product additions

- Point-in-Time direct/diffuse/total illuminance and CIE-overcast Daylight Factor.
- Climate-based sDA, direct-only ASE, four-bin UDI, sensor distributions, and area-weighted project metrics.
- RGB energy-conserving optical materials shared by Fast Path and Radiance export.
- Exact, process-memory daylight-coefficient reuse with visible cache-hit state and matrix hash.
- Exact instanced world-geometry Radiance export and material mapping.
- Cancellable point and annual Radiance runners with weather-independent coefficient-matrix reuse.
- Fast Path versus Radiance scientific error report.
- Additive C ABI and source-unit-aware .NET 8/.NET 10 SDK.
- Five Grasshopper components: `XV Optical`, `XV Daylight`, `XV Annual Daylight`, `XV Radiance`, and `XV Daylight Δ`.
- Seven CLI workflows: `daylight-point`, `daylight-factor`, `annual-daylight`, `radiance-export`, `radiance-point`, `radiance-annual`, and `daylight-compare`.

## Verification snapshot

- Rust HVARE analytic tests: 27 passing, including daylight and Radiance mapping/cancellation tests.
- C ABI crate tests: 30 passing, including complete daylight ABI traversal.
- Managed tests: 72 passing on .NET 8 and 72 passing on .NET 10.
- Rhino 8 connector builds on .NET 8; Rhino 9 connector builds on .NET 10.
- CLI point, DF, annual, export, and comparison smoke workflows pass.
- External Radiance tools were absent on the release host, so external binary execution is explicitly not marked as validated there.
