# XVARNA 0.2.0 — RASHNU Model Doctor

Release date: 2026-08-30

## Product outcome

This milestone delivers one complete vertical subsystem rather than isolated scaffolding. RASHNU is XVARNA's validation and audit subsystem; the same deterministic Rust mesh audit is usable from Rhino 8, Rhino 9, managed .NET code, the C API, and a standalone Windows CLI.

## User-facing capabilities

- `XV Mesh Check` in `XVARNA > 01 Scene`.
- Non-mutating audit plus optional conservative repaired output.
- Standalone OBJ `mesh-check` with human-readable or JSON output.
- Standalone OBJ `mesh-repair` with before/after hashes.
- Explicit distinction between **analysis-ready** open occluders and **watertight** volume meshes.
- Face and vertex attribution for repairable findings.
- Surface area, signed volume, bounds, component count, topology metrics, and f32 precision-risk estimate.

## Engineering evidence

- Rust 1.96.0 and official `x86_64-pc-windows-msvc` release target.
- BLAKE3 1.8.7 with a versioned canonical mesh preimage.
- Fixed C layout asserted as 224 bytes in native and managed code.
- Null-pointer, output-capacity, length-overflow, invalid-option, and panic containment at the FFI boundary.
- Identical managed source compiled for Rhino 8/.NET 8 and Rhino 9/.NET 10.
- Analytic open-quad, tetrahedron, and intentionally broken fixtures.
- `rustfmt`, strict Clippy, `dotnet format`, unit tests, ABI integration tests, CLI smoke tests, and SHA-256 release checksums.

## Deliberate limitations

- The OBJ importer accepts triangles and quads. N-gons above four vertices fail explicitly until a tested concave triangulator is selected.
- Conservative repair does not weld, fill holes, resolve self-intersections, reorient shells, or repair non-manifold topology.
- Estimated f32 error is a precision gate, not a GPU accuracy guarantee.
- Automated Rhino API compilation covers both hosts; interactive Rhino viewport smoke tests remain a release checklist item on the reference workstation.
- This milestone is Model Doctor, not yet the solar/daylight flagship workflow planned for 1.0.
