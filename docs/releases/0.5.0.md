# XVARNA 0.5.0 — ASMAN Sky Intelligence

Released 2026-08-31 as an engineering milestone for Windows x64, Rhino 8.20+/.NET 8, Rhino 9/.NET 10, the public C/.NET APIs, and the standalone CLI.

## Product capability

- `XV Sky View`: task-based oriented-sensor analysis with cosine SVF, visible hemisphere, solid angle, convergence diagnostics, dominant obstruction, counts, hash, report, and Viridis viewport heatmap.
- `XV Shadow Mask`: complete per-direction visibility and first-hit attribution with an interactive cyan/magenta dome.
- `xvarna sky-view`: headless OBJ analysis with repeated sensors, JSON summaries, and full Shadow Mask CSV export.

## Engine and API

- Deterministic seeded equal-solid-angle Fibonacci hemisphere sampling.
- Double-precision ZAMYAD closest-hit queries in bounded chunks.
- Full object/instance/mesh/triangle/distance attribution and deterministic dominant-object aggregation.
- New opaque native job handles with cancellation and progress counters.
- Additive 0.5 C ABI structures and entry points in `include/xvarna.h`.
- Public synchronous, cancellation-aware, and asynchronous .NET APIs for both supported runtimes.
- A separate Windows x64 SDK archive containing the C header, native engine, and .NET 8/.NET 10 assemblies.

## Validation

- Exact open/full-block analytic limits.
- A vertical half-screen acceptance case near 0.5.
- Determinism, seed variation, unit-direction, convergence, attribution, unit-conversion, cancellation, ABI-layout, and cross-runtime integration coverage.
- Scientific definitions and explicit non-claims are recorded in `docs/validation/sky-view-and-shadow-mask.md`.

## Compatibility

- Rhino 8 package: `net8.0` connector.
- Rhino 9 package: `net10.0` connector compiled against the Rhino 9 SDK.
- Native engine and CLI: Rust 1.96, Windows x64 MSVC release target.

This remains a pre-1.0 engineering release. It is a complete implemented milestone, not a claim that the final XVARNA 1.0 environmental platform is finished.
