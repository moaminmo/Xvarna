# XVARNA 1.0.0-rc.1 — Phase 1 freeze candidate

Status: **candidate implementation; Phase 1 acceptance not yet signed**.

This candidate freezes the 49-capability semantic catalog across Rhino 8/GH1, Rhino 9/GH1 and Rhino 9/GH2. GH1 components have product icons; GH2 uses vector icons and forwards host cancellation. GH2 Basic inputs now cover direct Target/Weighted/Green View, Intervisibility/Privacy, Sky View, annual irradiance, point and annual daylight, Radiance export, scalar/vector Study Manifest and atomic Study Commit workflows; optional JSON remains for expert import/automation.

Diagnostics can now emit a privacy-redacted support ZIP with host/runtime, engine/ABI, adapter, cache, scheduler and error/event context. It deliberately excludes model geometry, weather, environment variables and user documents. The twelve Rhino-generated tutorial canvases serialize all 49 component identities; structural coverage is checked during generation.

Documentation now contains 49 component reference pages and twelve Rhino-generated GH1 tutorial canvases. Runtime gates construct all 49 capabilities, validate unique IDs and GH1/GH2 identity, and execute representative native scene, GPU/fallback, daylight, view, Study and Evidence contracts.

No public superiority claim is made. Fast Path daylight remains a screening model with an explicit Radiance validation route. Rhino 8 supports GH1; the pinned prerelease GH2 SDK requires Rhino 9.

Phase 1 is not PASS until clean Yak installation, 49×3 interactive place/wire/solve/save/reopen evidence, cancellation/device-loss observations, independent onboarding under 15 minutes, clean full-check artifact and owner sign-off are complete.
