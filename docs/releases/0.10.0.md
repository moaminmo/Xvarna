# XVARNA 0.10.0 — VAYU Portable Compute

Released 2026-09-01 as a complete engineering milestone toward the 1.0 flagship.

## Product workflows

- `XV Devices`: adapter/driver/API discovery.
- `XV Backend`: cached Auto/GPU/CPU session with adapter filtering, precision, resource, memory, and fallback provenance.
- `XV Ray Query`: compatible with both canonical scenes and VAYU sessions, with backend/timing output.
- `xvarna devices`: text or schema-versioned JSON discovery.
- `xvarna backend-benchmark`: adapter-selectable CPU/GPU parity and end-to-end throughput evidence.

## Engine and API

- Rust `xvarna-vayu` on wgpu 30.0.1 and WGSL.
- Origin-rebased f32 world snapshot with deterministic global SAH BVH.
- Bounded closest-hit and any-hit compute traversal.
- Exact 64-bit object, instance, mesh, and category packing.
- Deterministic chunking and ordered readback.
- Additive C ABI, adapter-filtered session creation, and safe .NET 8/.NET 10 sessions.
- Rhino 8/.NET 8 and Rhino 9/.NET 10 packages share the same native engine.

## Validation boundary

NVIDIA RTX 5060 Laptop GPU and Intel Raptor Lake integrated graphics passed the documented real-device smoke corpus with zero state/identity mismatches. This release does not claim universal GPU speedup or high-level DAENA/HVARE backend migration. See `docs/validation/portable-gpu.md` for numeric and non-claim boundaries.
