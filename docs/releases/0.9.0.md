# XVARNA 0.9.0 — DAENA Advanced View + VAHMAN Study

This engineering release completes the first direct analysis-to-optimization loop. DAENA now measures raw target visibility, declared view quality, green view, protected corridors, and moving observers. VAHMAN ranks imported studies and produces deterministic mixed-variable constrained candidates through a native ask/tell lifecycle.

## Product workflows

- `XV Target View`: solid-angle Target / Weighted / Green View with target aggregation and blocker attribution.
- `XV Corridor`: circular-aperture protection with open fraction, convergence, and conflict source.
- `XV View Path`: tangent-facing path sampling, full view series, distance-weighted means, and hotspots.
- `XV Study`: constraint-aware Pareto fronts, crowding, exact 2D hypervolume, and descriptive Spearman diagnostics.
- `XV Optimizer` + `XV Opt Step`: explicit external-evaluation generations for arbitrary Grasshopper analysis graphs.

The same capabilities are available through Rust, the public C header, .NET 8/10, and new CLI commands. Every result records policy and deterministic identity. See [the validation contract](../validation/advanced-view-and-optimization.md).

## Compatibility

- Rhino 8.20+ connector: `net8.0`
- Rhino 9 connector: `net10.0`
- Native core: Rust 1.96 stable, edition 2024
- Windows release ABI: `0.9.0`, additive relative to 0.8
