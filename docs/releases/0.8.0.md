# XVARNA 0.8.0 — DAENA Spatial Visibility

Released 2026-08-31 as a complete engineering milestone toward the 1.0 flagship.

## Product release

- New `xvarna-daena` Rust engine for deterministic planar isovists, directed intervisibility/privacy matrices, and exact visibility graphs over ZAMYAD.
- Complete isovist polygons and radial records with area, perimeter, centroid distance, min/mean/max/standard-deviation/skew depth, compactness, convergence, open/occluded state, and dominant first blocker.
- Complete observer-target states and first object/instance/mesh/triangle identity plus a declared distance- and direction-weighted privacy-screening formula.
- Exact unordered visibility pairs, degree, normalized degree centrality, connected components, harmonic closeness, and Brandes betweenness.
- `XV Isovist`, `XV Intervisibility`, and `XV Visibility Graph` for both Rhino 8/.NET 8 and Rhino 9/.NET 10, including Data Trees and native Rhino output geometry.
- Public Rust, C, .NET 8/10, and CLI surfaces. CLI exports complete isovist boundaries, visibility matrices, graph pairs, and graph metrics as CSV, with schema-versioned JSON summaries.
- Deterministic hashes, category filtering, source-model unit round trips, endpoint clearance, resource ceilings, and explicit approximation/non-compliance labels.

## Validation

The release includes analytic square-room isovist area/perimeter convergence, divider attribution, category filtering, privacy bounds, graph component/centrality, fixed C layout, dual-managed-runtime, CLI export, Rhino 8 runtime-load, and Rhino 9 SDK compile gates. Equations, assumptions, limitations, and source references are public in `docs/validation/spatial-visibility-and-privacy.md`.
