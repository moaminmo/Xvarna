# XVARNA 0.3.0 — ZAMYAD Scene Engine

Released 2026-08-31 as an engineering milestone for Windows x64, Rhino 8.20+/.NET 8, Rhino 9/.NET 10, and the standalone CLI.

## Product surface

- `XV Scene`: reusable resources, affine instances, exact IDs, category masks, document-unit conversion, deterministic scene identity, hierarchy/memory/build diagnostics.
- `XV Ray Query`: ordered closest or any-hit batches with model-space points/distances and full closest-hit attribution.
- `XvarnaSceneBuilder` and `XvarnaScene`: public managed API with native safe-handle ownership and concurrent query support.
- `xvarna scene-bench`: repeatable OBJ scene compilation, throughput reporting, and analytic differential validation.
- `include/xvarna.h`: fixed-layout, opaque-handle C API for build/query/release.

## Native implementation

- Rust 1.96, `f64` geometry and traversal.
- BLAKE3 content deduplication with equality confirmation.
- Deterministic flattened BLAS/TLAS with 16-bin SAH and configurable leaves.
- Origin rebasing and canonical metre normalization.
- Scene-owned Rayon worker pool and ordered batch output.
- Explicit object, instance, mesh, triangle, barycentric, distance, category, and facing contracts.

## Verification shipped with the source

- Scene unit tests for transforms, deterministic hierarchy, deduplication, category masks, large coordinates, attribution, and 1,024-ray differential comparison.
- ABI layout/lifecycle tests including double release and real native traversal.
- Managed tests on both .NET 8 and .NET 10 for millimetre conversion, deduplication, category masks, attribution, concurrent 1,024-ray batches, and invalid geometry.
- CLI differential validation of the first 2,048 rays for every `scene-bench` run.

Rhino 9 is compile-validated against its official SDK on this development host; an interactive Rhino 9 smoke test remains a publication gate until Rhino 9 is installed on a release machine.
