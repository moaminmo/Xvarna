# XVARNA 1.0 tutorials

These twelve tutorials use the native Grasshopper 1 canvases in `examples/grasshopper`. The canvases are generated by Rhino from the packaged component assembly; they are not hand-written XML. Use small procedural boxes/meshes in Rhino and `validation/weather/tehran-mini.epw` where weather is required. Before recording evidence, set XV Units, run XV Mesh Check, and retain result hashes and backend/cache reports.

## 01 — Preflight (5 minutes)

Open `01-xvarna-preflight.ghx`; verify XV Info is ready, select Balanced quality, confirm model units, enumerate devices, set cache/scheduler budgets and run Diagnostics. Stop on ERROR. Outputs are configuration/provenance values, not physical results.

## 02 — Scene and ray/visibility foundations

Open `02-vayu-scene-visibility.ghx`; reference a box mesh, assign stable object/category IDs, build the scene and backend, then query rays and spatial analyses. Distances follow model units. Verify object attribution and scene hash; coincident/degenerate inputs are invalid.

## 03 — Solar and daylight overview

Open `03-hvare-daylight-solar.ghx`; connect a scene, sensor points/normals and the mini EPW. Point illuminance is lux; annual metrics are percentages/hours. Fast Path is for reproducible screening and must be compared with Radiance for publication evidence.

## 04 — Durable Study and report

Open `04-vahman-study-report.ghx`; define bounded parameters and scalar/vector objectives, create a workspace, evaluate every returned candidate, commit the aligned batch, then generate HTML/Parquet/glTF. Never edit the journal or reorder candidate IDs.

## 05 — Sensitivity and multi-fidelity evidence

Open `05-rashnu-evidence-multifidelity.ghx`; generate a Saltelli/Jansen or Morris design, evaluate every row in order, analyse responses, seal evidence, then select costly reference runs by value per cost. Sensitivity applies only to declared ranges.

## 06 — Urban sun hours and blockers

Open `06-urban-sun-hours.ghx`; use one ground sensor and two massing boxes, create a fixed-offset period, compute sun vectors and Sun Hours, then map the dominant blocker ID with Highlight. Duration is hours and depends on the sampling interval/weights.

## 07 — Parametric shade with scene delta

Open `07-parametric-shade-delta.ghx`; keep context static and move only a dynamic shade mesh. Recompute Shadow Mask/Solar Potential and inspect scene revision plus refit/rebuild/cache telemetry. A changed stable ID defeats intended incremental reuse.

## 08 — Target, Weighted and Green View

Open `08-target-weighted-green-view.ghx`; connect eyes, forward vectors and target meshes directly. Set category/green masks and optional desirability weights. Compare raw target solid angle, weighted score and GVI separately; sample convergence is reported, not assumed.

## 09 — Facade intervisibility and privacy

Open `09-facade-privacy.ghx`; connect observer and facade target points, optional target facings, weights and sensitivities. Inspect directed states, distances, target exposure, privacy risk and blocker IDs. Risk is a transparent screening score, not a legal privacy conclusion.

## 10 — Annual daylight plus Radiance reference

Open `10-annual-daylight-reference.ghx`; create workplane sensors, assign optical materials, run the mini EPW through annual sDA/ASE/UDI, export the identical scene/sensors to Radiance and compare aligned lux values. Preserve commands, versions and validation statistics.

## 11 — Dynamic observer path and protected corridor

Open `11-dynamic-observer-corridor.ghx`; define a path, camera orientation and target/landmark geometry, then compute path quality, corridor conflicts and local 3D isovists. Keep path timestamps/order and coordinate units consistent.

## 12 — End-to-end decision evidence

Open `12-end-to-end-decision-report.ghx`; combine solar/daylight/view objectives in a manifest, evaluate candidate batches, rank feasible Pareto options, attach Evidence Passports and export the self-contained viewer/report. Checkpoint before closing and reopen the workspace to prove reproducibility.

## Verification

Regenerate all canvases with `eng/generate-gh-examples.ps1`. Automated registration/runtime checks are performed by `eng/test-rhino8-compat.ps1`, `eng/test-rhino9-compat.ps1`, and `eng/test-grasshopper2-compat.ps1`. Interactive wiring, save/reopen and first-user timing remain acceptance observations and must be recorded under `artifacts/acceptance/phase-1`.
