XVARNA — راهنمای نصب و تست

نسخهٔ تست 1.0.0-rc.1 برای ویندوز ۶۴ بیتی. برای شروع فقط راینو و گرس‌هاپر لازم است؛ نصب Rust، Python یا ابزارهای برنامه‌نویسی لازم نیست.

۱. نصب پلاگین در گرس‌هاپر ۱

  1. روی فایل ZIP دریافتی راست‌کلیک کن، Properties را باز کن و اگر گزینهٔ Unblock وجود دارد آن را فعال و Apply کن. سپس ZIP را کامل با Extract All در یک پوشهٔ ثابت استخراج کن. فایل را از داخل ZIP اجرا نکن.
  2. اگر راینو ۸ داری، پوشهٔ Plugin/Rhino8 را انتخاب کن. اگر راینو ۹ داری، پوشهٔ Plugin/Rhino9 را انتخاب کن. فقط پوشهٔ مربوط به نسخهٔ راینو خودت را معرفی کن.
  3. در راینو گرس‌هاپر را باز کن. در خط فرمان راینو دستور GrasshopperDeveloperSettings را اجرا کن و پوشهٔ انتخاب‌شده را به فهرست مسیرهای کتابخانهٔ گرس‌هاپر اضافه کن.
  4. راینو را کامل ببند و دوباره باز کن. در گرس‌هاپر تب XVARNA را پیدا کن. در بخش 00 Setup کامپوننت XV Info را روی بوم بگذار؛ خروجی Ready باید True باشد.
سه فایل Xvarna.Grasshopper.gha، Xvarna.Native.dll و xvarna_core.dll باید همیشه کنار هم بمانند. اگر نسخهٔ قدیمی XVARNA نصب کرده‌ای، مسیر آن را از کتابخانه خارج کن تا دو نسخه هم‌زمان بارگذاری نشوند. این بسته برای راینو ۸٫۲۰ به بعد با runtime دات‌نت ۸، و راینو ۹ با دات‌نت ۱۰ ساخته شده است.

۲. باز کردن مثال‌ها

در گرس‌هاپر ۱ از File → Open یکی از فایل‌های پوشهٔ Examples را باز کن. برای شروع 01-xvarna-preflight.ghx مناسب است.

مثال‌ها قالب آموزشی با کامپوننت‌های چیده‌شده و پنل توضیح هستند؛ سیم‌کشی، هندسه و همهٔ ورودی‌ها از پیش آماده نیستند. باید ورودی‌ها را وصل کنی. بنابراین نارنجی بودن کامپوننتی که هنوز ورودی ندارد، به‌تنهایی نشانهٔ خرابی پلاگین نیست.

برای یک تست ساده: در راینو یک Mesh بساز؛ آن را با پارامتر Mesh گرس‌هاپر به ورودی هندسهٔ XV Scene وصل کن. خروجی Scene را به XV Ray Query بده و یک نقطهٔ شروع و بردار به سمت مش تعیین کن. با تغییر نقطه یا جهت، برخورد و فاصله را بررسی کن. برای دیدن معنی ورودی و خروجی‌ها، نشانگر ماوس را روی پورت نگه دار.

۳. اگر گرس‌هاپر ۲ را تست می‌کنی

در راینو ۹، دستور PlugInManager را اجرا کن؛ از Install فایل Plugin/Rhino9/Xvarna.Grasshopper2.rhp را معرفی و راینو را دوباره باز کن. فایل‌های DLL همان پوشه را جابه‌جا نکن. سپس گرس‌هاپر ۲ را باز و کامپوننت‌های XVARNA را جست‌وجو کن.

این اتصال با SDK پیش‌انتشار 9.0.26237.15343-beta ساخته شده و نسخهٔ WIP میزبان می‌تواند روی بارگذاری اثر بگذارد. فایل‌های .ghx این بسته برای گرس‌هاپر ۱ هستند؛ مثال بومی ذخیره‌شدهٔ گرس‌هاپر ۲ در این بسته وجود ندارد و برای تست آن باید کامپوننت‌ها را روی بوم خودش بچینی.

۴. موارد کاربردی هنگام تست

  • راهنمای کاربرد ۴۹ کامپوننت را باز کن؛ بدون اینترنت و در مرورگر خوانده می‌شود.
  • برای تحلیل سالانه، مسیر فایل آب‌وهوایی EPW محل پروژه را بده. این فایل داخل بسته نیست.
  • نور روز سریع به Radiance نیاز ندارد. XV Radiance فایل‌های صحنه را برای Radiance خروجی می‌گیرد؛ اجرای محاسبهٔ مرجع به نصب جداگانهٔ Radiance و runner نیاز دارد که در این بستهٔ ساده قرار نگرفته‌اند.
  • اگر تب XVARNA ظاهر نشد: نسخهٔ پوشه، مسیر کتابخانه، Unblock و نبود نصب تکراری را بررسی کن. اگر Ready=False شد، کنار هم بودن DLLها و متن پیام کامپوننت را بررسی کن.
  • برای حذف نصب، مسیر XVARNA را از کتابخانهٔ گرس‌هاپر حذف کن؛ برای GH2 پلاگین را در PlugInManager غیرفعال کن. بعد از بستن راینو می‌توانی پوشهٔ استخراج‌شده را حذف کنی.

چه بازخوردی بفرستی؟

کافی است بگویی چه نسخه‌ای از راینو و گرس‌هاپر داشتی، کدام مثال یا کامپوننت را امتحان کردی و چه چیزی درست کار نکرد یا نامفهوم بود. اگر خطایی دیدی، متن یا عکس آن همراه نام کامپوننت کافی است؛ فرم مفصل لازم نیست.
